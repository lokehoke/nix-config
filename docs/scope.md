# Согласованный состав

Решения пользователя внесены в PR. Слияния и применения конфигурации к текущему ноутбуку не было.

| Категория | Решение |
| --- | --- |
| Система | Ubuntu + standalone Home Manager, x86_64; аппаратная конфигурация не привязана к модели ноутбука |
| Shell | Сохранить zsh/agnoster и алиасы; корпоративную инициализацию Skotty убрать |
| tmux | Автоподключение к `home` и автообновления плагинов включить |
| Vim | Перенести все 6 найденных плагинов на исходных коммитах и локальные изменения; личного vimrc не найдено |
| CLI | Весь предложенный набор и обнаруженные пользовательские утилиты, включая gh, links, neofetch, f3, OCR/сертификаты/ESP/Proton tools; системные службы остаются Ubuntu |
| Разработка | Python/Jupyter, JS/Node 22, C/C++ с GCC/GDB, make, CMake, pkg-config; версии зависимостей отдельных проектов можно фиксировать отдельно |
| VS Code | Установка через Nix; 12 исходных расширений без Roo Code; AI только Claude Code и Codex |
| Браузеры и почта | Firefox, Chromium, Yandex Browser и Thunderbird исключены |
| Связь и API | Telegram, Discord, Zoom, Postman — все |
| Документы/медиа | Obsidian, LibreOffice, GIMP, VLC, Flameshot, Remmina, Transmission, Pavucontrol — все |
| Defaults | Перенести текущие эффективные MIME-обработчики; установить нужные GNOME-программы; исключения браузеров и переименование snap-ID записаны отдельно |
| Музыка | REAPER, Ardour, QjackCtl, Vital и VST3 не переносить |
| AI | Claude/Codex CLI, desktop, расширения и переносимые настройки; вся остальная история/skills/MCP/авторизация — приватным переносом |
| Корпоративное | UEM, Salt, osquery, Skotty/TPM, VPN/внутренние CA, Arc/ya не включать |

Neofetch в закреплённом nixpkgs удалён. Используется fastfetch с командой-обёрткой `neofetch`; старые специфические флаги и формат вывода не гарантируются.

## Vim

`vim-eunuch`, `vim-surround`, `nginx.vim`, `vim-colorschemes`, `vim-matlab`, `Vundle.vim`. Нынешние изменения vim-colorschemes — снятые executable-биты у `scripts/toremove` и `scripts/toremove2`; они воспроизводятся в сборке. Плагины подключаются штатным механизмом Vim packages через Home Manager, поэтому команда установки Vundle не нужна.

## Оставшиеся действия на новом ноутбуке

- Проверить desktop-приложения, графику, portals, URI handlers и keyring; при необходимости настроить GPU-интеграцию.
- Создать отдельный приватный бэкап данных и Claude/Codex по перечню путей; хранилище ещё не выбирали.
- Восстановить личные проекты/заметки/файлы и приватный Git/SSH-конфиг; проверить доступность внешних ресурсов.
- Для другой архитектуры, имени пользователя или HOME адаптировать конфиг. Под «любой новый ноутбук» здесь понимается отсутствие привязки к модели в пределах выбранной Linux x86_64 платформы.
