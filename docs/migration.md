# Что осталось перенести

## Программы и настройки

- Проверить все профили на новом ноутбуке, особенно GPU, GTK/Qt, захват экрана и системный keyring.
- Восстановить приватный SSH-конфиг, Git identity, shell-переменные и rclone.conf отдельно от Git/Nix.
- Рабочие пакеты Яндекса, UEM, Salt, osquery, внутренние CA, Skotty, TPM/PKCS#11 и VPN устанавливать по штатной процедуре Ubuntu. Новый TPM может требовать повторной выдачи ключей.
- VirtualBox/DKMS, ядро, загрузчик, LUKS, PAM, NetworkManager и системное аудио остаются под управлением Ubuntu.
- ChatGPT/Codex Desktop, Claude Desktop, chats, Yandex Browser/Messenger, splitty: проверить официальные способы установки. CLI Codex/Claude доступны отдельной опцией.
- Остальные расширения VS Code из inventory пока устанавливаются вручную или добавляются с проверенными хэшами Marketplace. Не импортировать разрешения AI-агентов вслепую.
- Vim-плагины пока не перенесены: в vim-colorschemes есть локальные изменения, которые нужно отдельно сохранить.
- Jupyter, Python-библиотеки и специфические C/C++ зависимости описывать в devShell каждого проекта, не переносить все user pip-пакеты одним глобальным окружением.
- Vital, пользовательские VST3, пресеты и лицензии: сохранить отдельно; аудиопрофиль пока включает только REAPER, Ardour, QjackCtl.
- Electrum/Exodus и игровые программы: отдельный следующий этап после проверки восстановления данных и способов установки.
- Сохранить `~/scripts/ssh_vm.sh` отдельно как приватный рабочий скрипт: алиас `cvm` указывает на него. Файл существует и исполняемый; его содержимое не публикуется.

## Данные

Репозиторий не является бэкапом. Сохранять отдельно Pictures/yadisk, Downloads после разбора, mathematics вместе с ignored-файлами и .git, tmp/pdfs, webcatalog-hostcheck, goods-admin-*, Obsidian, output, почту, аудиопроекты, сейвы, AI-чаты и браузерные профили. Подробный приватный отчёт находится в `~/migration-audit/REPORT.ru.txt` и не публикуется.

Полнота облачной синхронизации, Arc-ветки/локальные изменения, root cron, закрытые системные данные и внешние диски пока не проверены. Не исключать Arc stores как простой кэш до этой проверки. Сломанные старые ссылки `~/.local/bin/ya` и `~/.local/bin/claude` не воспроизводятся.
