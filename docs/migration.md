# Перенос личных данных

Этот PR описывает программы и открытые настройки. Бэкап ещё не создавался: место хранения пользователь пока не выбирал.

## Claude и Codex целиком

[Манифест](../inventory/private-transfer.json) перечисляет каталоги CLI/desktop, настройки, skills/rules/instructions, plugins/hooks/MCP, чаты, file history, SQLite-базы, результаты генерации и авторизацию. В Git находятся только имена путей.

Перед копированием закрыть Claude, Codex и VS Code. Базы копировать вместе с журналами после завершения процессов; сокеты, SingletonLock и runtime IPC не переносить. Приватные файлы хранить в защищённом бэкапе. При восстановлении сохранить прежние имя пользователя и пути проектов, затем проверить настройки и войти в аккаунты при необходимости. Перед первым запуском можно восстановить полный config поверх начальных безопасных предпочтений из Nix.

Настройки Codex находятся в пользовательском config.toml, а проектные настройки — рядом с проектами: [официальная документация](https://learn.chatgpt.com/docs/config-file/config-basic). Поэтому перенос каталогов приложений дополняется переносом самих проектов.

## Другие данные

Сохранить Pictures/yadisk, Downloads после разбора, mathematics целиком вместе с ignored-файлами и Git, tmp/pdfs, webcatalog-hostcheck, Obsidian, output и нужные остальные файлы из приватной ревизии `~/migration-audit/REPORT.ru.txt`. Исключение программы из Nix не означает разрешения удалять её существующие данные.

Приватный SSH-конфиг, Git identity, shell-переменные и rclone.conf восстанавливаются отдельно от публичного Git. Системные службы Ubuntu и данные других пользователей не входят в Home Manager.

Программы для записи музыки, корпоративные инструменты и графические браузеры не включаются по решению пользователя. Профиль `lokehoke-audio` удалён. Графика, TPM, VPN и корпоративная регистрация автоматически не настраиваются.
